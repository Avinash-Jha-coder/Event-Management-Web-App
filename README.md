# Event Management Web App

A full-stack Event Management platform built using React (frontend) and Node.js (backend).  
It allows users to create events, manage attendees, upload images, and view all events in a clean dashboard.

---

## 🚀 Features

- Create, update, and delete events  
- Upload event images (file upload, not URL)  
- View all events in a responsive grid  
- Personal user information section  
- Modern UI design  
- Backend API with Node.js + Express  
- MongoDB / SQL support (depending on your setup)  

---

## 🛠️ Tech Stack

### **Frontend**
- React.js  
- React Router  
- CSS / Tailwind (if used)  
- Axios  

### **Backend**
- Node.js  
- Express.js  
- Multer (for image upload)  
- Database (MongoDB or MySQL depending on your setup)
